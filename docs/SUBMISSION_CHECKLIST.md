# Submission checklist

| Requirement | Delivered location |
| --- | --- |
| Complete Python and JavaScript application | `app/`, `run.py`, `requirements.txt` |
| Admin and Sales User permissions | API decorators and order ownership checks |
| Six database entities, keys and constraints | `app/models.py`, `sql/schema.sql` |
| Sample accounts, customers and products | `python -m flask --app run seed` |
| Customer and product CRUD, search, filters | Master screens and authenticated API |
| Draft orders, saved prices, discounts | Order editor and `app/services.py` |
| Transactional confirmation and cancellation | Locked order and product updates with MySQL tests |
| Stock adjustments and movement history | Product adjustments and movement report |
| Dynamic rows, live calculations and fetch | `app/static/app.js` |
| JSON API and examples | `docs/API.md` |
| Four reports and five SQL queries | Reports screen and `sql/reports.sql` |
| All-or-nothing CSV import | Import screen and `samples/` |
| Debugging fix, explanation and tests | `debugging.py`, `docs/DEBUGGING.md`, tests |
| Automated tests and run instructions | `tests/`, `README.md`, `docs/VERIFICATION.md` |
| Git history, feature branch and merge | Included `.git` repository |
| AI disclosure | `AI_USAGE.md` |
| 5-8 minute demonstration | `demo/Assignment_Demo.mp4` |

The archive uses the placeholder name `FullName_TechnicalAssignment`. Replace FullName with your actual full name before submitting. The local `.env`, virtual environment and MySQL data are excluded. The receiver follows README.md to create their own environment and credentials. The demo uses captions and has no voice narration.

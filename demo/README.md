# Assignment demonstration

`Assignment_Demo.mp4` is a 5 minute 38 second live browser recording with explanatory captions. It covers login, customer creation, products, multi-item orders, discounts, stock confirmation and cancellation, insufficient-stock rejection, adjustments, CSV validation and import, reports and Sales User permissions.

There is no voice narration. The candidate can use `docs/DEMO_SCRIPT.md` to prepare a personally narrated presentation if desired.
